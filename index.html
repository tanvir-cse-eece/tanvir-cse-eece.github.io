Selected Projects

Best Fit
Computer Vision

OpenWorld Scene Grounding for Embodied Vision

  • Problem: Ground free-form instructions in open-set indoor scenes.
  • Role: Pipeline design, training, ablation, and error analysis.
  • Datasets: ScanRefer, RefCOCOg, synthetic hard negatives.
  • Method: Cross-attention vision-language transformer.
  • Metrics: Acc@0.5 IoU, grounding recall, latency.
  • Results: +4.8 Acc@0.5 and 18% lower inference latency.
  • Learned: Hard-negative curation improved robustness most.
Code Poster Technical Report
NLP

Low-Resource Multilingual Reasoning with Test-Time Adaptation

  • Problem: Stabilize reasoning quality for low-resource languages.
  • Role: Adaptation strategy, evaluation harness, analysis.
  • Datasets: XNLI, FLORES subsets, multilingual QA.
  • Method: Test-time adaptation with confidence-aware decoding.
  • Metrics: Exact Match, F1, calibration error.
  • Results: +6.1 F1 average over baseline in 5 languages.
  • Learned: Calibration matters more than raw score boosts.
Code Slides Notes
ML Security

PoisonWatch for Foundation Model Fine-Tuning

  • Problem: Detect poisoned mini-batches before downstream degradation.
  • Role: Detector design, threat modeling, benchmark creation.
  • Datasets: Instruction-tuning corpora with controlled poisoning.
  • Method: Gradient-statistics anomaly ensemble.
  • Metrics: AUC, false positive rate, attack success reduction.
  • Results: 0.91 AUC and 43% attack success reduction.
  • Learned: Gradient drift alerts are early and practical indicators.
Code Experiment Logs Draft Paper
Graph Learning

GraphReasoner for Scientific Claim Verification

  • Problem: Verify long-chain scientific claims with explicit evidence.
  • Role: Graph schema design and retrieval reasoning pipeline.
  • Datasets: SciFact, PubMed claim snapshots.
  • Method: Retrieval-augmented graph reasoner + symbolic checks.
  • Metrics: Evidence F1, verification accuracy, ECE.
  • Results: +5.3 Evidence F1 with better calibration.
  • Learned: Graph structure improves explainability and debugging.
Code Poster Working Paper
