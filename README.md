## Portfolio Structure

- Home
- About
- Research
- Projects
- Publications
- Code
- CV
- Contact

## What This Site Emphasizes

- Clear research identity on the homepage
- Focused research interests (not broad skill dumping)
- Selected projects in mini-paper style (problem, method, metrics, results)
- Publications, preprints, and working-paper readiness
- Code and reproducibility signals for each project
- CV download and easy faculty contact routes
